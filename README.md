# TDAH au travail — BUILD RH

Carrousel **BUILD RH / Neuro-inclusion** : comprendre les forces, les frictions et les conditions de réussite des personnes TDAH au travail (recrutement & management).

Version web interactive en 10 diapositives — ouvrez `index.html` dans un navigateur, ou consultez la version en ligne via GitHub Pages.

**Navigation :** flèches ← → du clavier, boutons à l'écran, ou glisser sur mobile. Chaque diapositive a son lien direct (`#1` à `#10`).

## Sommaire

1. Couverture — *Ce n'est pas un défaut de volonté. C'est un autre mode de fonctionnement.*
2. Comprendre — Le cerveau ne décroche pas au hasard
3. Potentiel — Les forces apparaissent quand le cadre est bon
4. Réalité du quotidien — Les frictions sont souvent invisibles
5. Environnement — Les bons terrains : des conditions avant des métiers
6. Statut — Freelance ou CDI : aucun statut n'est magique
7. Recrutement — On juge encore trop souvent la forme, pas le fond
8. Recruter autrement — Le recrutement zéro bullshit
9. Management — Manager sans abîmer
10. La vraie question : compétence ou conformité ?

*Témoignages recueillis et éditorialisés par BUILD RH. Les expériences varient d'une personne à l'autre. Ce contenu ne constitue pas un diagnostic médical.*
